







# Amazon Fine Food Reviews – NLP & EDA

This project performs Exploratory Data Analysis (EDA) and Natural Language Processing (NLP) on Amazon Fine Food Reviews.

## Project Objectives
- Analyze Amazon customer reviews
- Clean and preprocess review text
- Perform sentiment analysis
- Identify frequently used words and phrases
- Visualize review patterns and insights

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- NLTK
- Jupyter Notebook

## Dataset
Amazon Fine Food Reviews dataset.

## Project File
- `Amazon_Reviews_Text_EDA.ipynb` – Complete EDA and NLP analysis
